## 한 줄 요약

교차검증 순위 성능(AUC)이 좋아도 **판정 컷오프를 평가 분포와 난이도·양성 비율이 다른 집합에서 정하면 예측이 한쪽으로 쏠려 균형 평가 점수가 낮은 곳에서 막힌다** — 점수가 기대보다 낮으면 운을 탓하기 전에 예측 양성 비율부터 센다.

## 내용

- 증상: 교차검증 성능이 좋던 이진 판정 모델이 양성·음성이 반반인 평가셋 21건에서 전부-양성 기준선보다 겨우 두 케이스 더 맞혔다. 미리 적어 둔 예상 범위 안이었고 21건이면 1회 오차가 ±0.11 수준이라, 점수 하나로는 운인지 결함인지 가를 수 없었다.
- 진단 순서: (1) 실행 실패·폴백 여부 → 전부 정상. (2) 학습 데이터 생성 경로와 평가 경로의 불일치 → 같은 문제에서 두 경로(vLLM·HF)의 토큰 상한 내 완료율이 일치해 배제. (3) 예측 분포 → 양성 예측이 21건 중 3건, 한 모델군은 11건 중 0건. 원인은 (3)이었다.
- 원인: 컷오프를 공식 학습 케이스(평가셋보다 쉽고 양성 74%)에 맞춰 정하자 기준점보다 한참 '쉬운 쪽'에 놓였다. 평가셋 점수는 기준점 근처에 몰려 있어 거의 전부 음성으로 판정됐고, 균형 평가를 가정한 class weighting이 쏠림을 더 키웠다.
- 수정: 모델과 피처는 그대로 두고 컷오프만 설계 기준점(각 모델 자기 분포의 중앙)으로 옮겼다. 학습 케이스 성능은 사실상 같았고(balanced accuracy 차이 0.005), 같은 평가 피처에 적용하면 양성 예측이 21건 중 10건으로 균형이 맞았다. 수정판의 실제 평가 점수는 세션 안에서 확인하지 못했다.
- 방증: 교차검증 AUC가 더 낮은 단순 버전은 양성을 21건 중 9건으로 덜 쏠리게 예측했고, 평가 점수는 오히려 두 케이스 더 높았다. 순위 성능과 임계값은 서로 다른 실패 지점이다.
- 예방 규칙: 제출 전에 배포와 비슷한 무라벨 입력 풀에서 예측 양성 비율을 계산해 기대 비율과 비교한다. 무라벨 입력의 점수 분포는 테스트 시점에도 보이는 정보라 임계값 위치 점검에 쓸 수 있다.
- 일반화: 보정용 집합의 사전확률·난이도가 배포 집합과 다르면 순위는 유지돼도 최적 임계값은 이동한다. 점수 옆에 예측 양성 비율을 항상 함께 기록하면 이 고장이 바로 보인다.
