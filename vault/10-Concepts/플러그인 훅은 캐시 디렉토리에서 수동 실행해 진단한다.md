## 한 줄 요약

플러그인 훅이 에러를 내는 것 같으면 `~/.claude/plugins/cache/`의 실제 설치본에서 훅 스크립트를 직접 실행해 exit code를 확인한다 — 진짜 실패와 겉치레 메시지를 이것으로 가른다.

## 내용

- 진단 경로: `~/.claude/plugins/cache/<marketplace>/<plugin>/<hash>/`로 이동 → `hooks.json`을 읽어 어떤 이벤트에 어떤 스크립트가 걸려 있는지 파악.
- 그다음 훅 스크립트를 터미널에서 직접 실행하고 exit code를 확인 — 0이면 훅 자체는 정상, 0이 아니면 진짜 실패.
- 이번 사례: "에러"로 보였던 출력의 정체는 statusline이 설정 안 됐다는 안내(nag) 메시지였고, 훅 실패가 아니었음 — 수동 실행으로 즉시 판별.
- 세션 안에서 훅 에러 메시지만 보고 추측하면 안내문·경고·실제 실패가 전부 같은 "에러"로 뭉뚱그려짐. 수동 실행이 이 셋을 분리하는 유일한 확실한 방법.
- 응용: 캐시 경로의 `<hash>` 디렉토리가 실제 실행되는 버전이므로, 저장소 원본이 아니라 캐시본을 읽어야 지금 동작과 일치함.
